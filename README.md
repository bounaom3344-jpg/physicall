# ສື່ການສອນຟີຊິກ (Streamlit)

ສື່ການສອນ ແລະ ແບບທົດສອບຟີຊິກພື້ນຖານ ສຳລັບນັກສຶກສາປີ 1 ມະຫາວິທະຍາໄລ.

## ຕິດຕັ້ງ ແລະ ແລ່ນ

```
pip install -r requirements.txt
python -m streamlit run app.py
```

ຈາກນັ້ນເປີດໜ້າເວັບທີ່ http://localhost:8501 (ສາມາດຂື້ນຈໍຢູ່ໂປຣເຈັກເຕີໃນຫ້ອງຮຽນໄດ້ເລີຍ).

## ໂຄງສ້າງໄຟລ໌

| ໄຟລ໌ | ເນື້ອໃນ |
|---|---|
| `app.py` | ໄຟລ໌ຫຼັກ: ເມນູເລືອກບົດຮຽນ / ແບບທົດສອບ |
| `lessons_new.py` | ບົດຮຽນຫຼັກ 5 ຫົວຂໍ້: ການເຄື່ອນທີ່ຊື່, ແຮງ, ງານ, ພະລັງງານ, ແສງສະຫວ່າງ |
| `lessons_basic.py` | ບົດຮຽນເພີ່ມເຕີມ 8 ຫົວຂໍ້ (ໂປເຈັກໄທລ໌, ສະປຣິງ, ຄື້ນ, ພື້ນອຽງ, ການຊົນ, ສະໜາມໄຟຟ້າ, RC, ແກັສ) |
| `quiz.py` | ແບບທົດສອບ ແລະ ຄັງຄຳຖາມ (32 ຂໍ້) |

## ເພີ່ມຄຳຖາມໃໝ່

ເປີດ `quiz.py` ແລ້ວເພີ່ມ dict ໃນລາຍການຂອງຫົວຂໍ້ທີ່ຕ້ອງການ:

```python
{
    "q": "ຄຳຖາມ",
    "options": ["ຕົວເລືອກ ກ", "ຕົວເລືອກ ຂ", "ຕົວເລືອກ ຄ", "ຕົວເລືອກ ງ"],
    "answer": 1,          # ລຳດັບຄຳຕອບທີ່ຖືກ (ເລີ່ມນັບຈາກ 0)
    "explain": "ຄຳອະທິບາຍ",
},
```

## ເພີ່ມບົດຮຽນໃໝ່

ຂຽນຟັງຊັນໃໝ່ (ໃຊ້ `st.slider`, `st.plotly_chart` ຄືກັບຟັງຊັນອື່ນ) ແລ້ວເພີ່ມອີກແຖວໃນ dict `LESSONS` ຢູ່ `app.py`.
